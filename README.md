# Nico Nico Ranking NG fork

ニコニコ動画のランキングとキーワード・タグ検索結果に NG 機能を追加するユーザースクリプトです。

[Nico Nico Ranking NG](https://greasyfork.org/ja/scripts/880-nico-nico-ranking-ng)（MIT License）をフォークし、ページの不要な部分を非表示にしたり縮小したりする「その他設定」を追加しています。

## インストール

1. ブラウザにユーザースクリプトマネージャー（Tampermonkey など）を入れます。
2. 次のリンクを開き、表示されたインストール画面でインストールします。

   https://github.com/aoiteru/NicoNicoRankingNG_fork/raw/main/NicoNicoRankingNG_fork.user.js

更新があると、ユーザースクリプトマネージャーがこのリポジトリから自動で取得します。

## 対象ページ

- ランキング（`https://www.nicovideo.jp/ranking/genre/...`）
- キーワード検索（`https://www.nicovideo.jp/search/...`）
- タグ検索（`https://www.nicovideo.jp/tag/...`）

## 使い方

対象ページの上部に設定バーが表示されます。

```
閲覧済みの動画を [縮小▼] | 投稿者 [全部▼] | □NG動画を表示 | NG設定 | その他設定
```

動画にマウスを乗せると「閲覧済み」「NG登録」「NGタイトル追加」のボタンが出ます。動画の下の ▼ を押すと、タグと投稿者が表示されます。それぞれの [+] ボタンを押すと NG に登録できます。

### NG設定

元のスクリプトと同じ NG 機能です。

| 種類 | 判定方法 |
|---|---|
| NG動画ID | 完全一致 |
| NGタイトル | 部分一致（大文字小文字を区別しない） |
| NGタグ | 完全一致（大文字小文字を区別しない） |
| NGタグ(ロック) | ロックされたタグだけを対象に完全一致 |
| NGユーザーID | 完全一致 |
| NGユーザー名 | 部分一致（大文字小文字を区別しない） |
| NGチャンネルID | 完全一致 |

ほかに、閲覧済み動画の縮小・非表示、投稿者の種類（ユーザー／チャンネル）による絞り込み、NG リストの CSV エクスポート・インポートができます。

### その他設定（このフォークで追加）

チェックを入れるとすぐに反映され、外すと元の表示に戻ります。

| 設定 | 内容 |
|---|---|
| 左枠(メニュー)を非表示にする | ページ左のメニューを消して、本文を左に詰めます |
| ランキング中の「ニコニ広告」の動画を非表示にする | ランキングの間に挟まる、順位の無い広告動画の枠を消します |
| 右枠の個別タグランキングを非表示にする | 右枠の「例のアレ」などのタグ別ランキング（1〜3位）を消します |
| 右枠のニコニコニュースを非表示にする | 右枠のニコニコニュースのランキングを消します |
| 右枠の広告を非表示にする | 右枠の広告 3 枠を消します |
| 動画のサムネイルを縮小する | ランキングのサムネイルを 100%〜20% に縮小します |
| 動画のサムネイルの幅を固定する | ランキングのサムネイルの幅を、ブラウザの幅に関係なく 128px〜640px の指定の幅にします |
| サムネイル左上の「ニコニ広告」の帯を非表示にする | ニコニ広告された動画のサムネイル左上に付く帯を消します |
| ▼ボタン(タグ・投稿者の表示)の位置 | ランキングの各行の ▼ の位置を「右端」「従来の位置(右枠があったときの位置)」「順位の下」から選びます |
| 閲覧済み・NG登録・NGタイトル追加のボタンの位置 | マウスを乗せたときに出るボタンの位置を「右端」「従来の位置(右枠があったときの位置)」から選びます |

サムネイルの幅は、通常はブラウザの幅と高さに合わせて変わります。「幅を固定する」と「縮小する」を両方オンにすると、固定した幅にさらに倍率が掛かります（例: 256px で 50% なら 128px）。

右枠の 3 項目（個別タグランキング・ニコニコニュース・広告）をすべて非表示にすると、右枠の列を詰めて動画一覧を広げます。このとき ▼ やボタンは画面の右端まで離れるので、位置を「従来の位置」（▼ は「順位の下」も可）にすると押しやすくなります。右枠を詰めていないときは、「従来の位置」は「右端」と同じ位置です。

## 元のスクリプトから移行する場合

このフォークは、ユーザースクリプトマネージャーからは元のスクリプトとは別のスクリプトとして扱われます。NG リストは自動では引き継がれないので、次の手順で移してください。

1. 元のスクリプトで「設定」→「エクスポート」を開き、CSV をコピーします。
2. このフォークで「NG設定」→「インポート」に貼り付けて、インポートします。
3. 元のスクリプトを無効にするか、削除します（両方を有効にすると、設定バーが二重に表示されるなど正しく動きません）。

「NGタグ(ロック)」はエクスポートの対象に含まれません。使っている場合は、このフォークで登録し直してください。

## 注意

- ニコニコ動画のページ構造に合わせて要素を探しているため、サイトのレイアウトが変わると一部の機能が効かなくなることがあります。
- 左枠を非表示にしている間は、ヘッダーの「≡」（サイドメニュー）を押してもメニューは表示されません。
